## SUMMARY

Read the `SUMMARY` key in the run's default key-value store. `status="complete"` and `complete=true` identify a completed collection, which can legitimately have no matching rows. `partial` preserves saved rows but did not finish the requested work. `invalid_input` explains corrections in `inputIssues` and warnings; it is not a completed search. Required storage or financial uncertainty can fail the run. Platform `SUCCEEDED` alone is insufficient.
